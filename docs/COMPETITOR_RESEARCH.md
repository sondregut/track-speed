## Executive Summary

The sprint timing market is divided into two main categories:
1. **Professional Hardware Systems** - Dedicated timing gates ($500 - $10,000+)
2. **Mobile Apps** - Smartphone-based solutions (Free - $50)

Our app, **Track Speed**, aims to bridge the gap by providing professional-grade timing accuracy using smartphone cameras at a fraction of the cost.

## Mobile Apps

### 1. Photo Finish (photofinish-app.com)
**Platform:** iOS & Android
**Price:** Free (Basic) / Pro Subscription
**Website:** photofinish-app.com

#### How It Works
Photo Finish uses smartphone cameras with **image recognition to detect an athlete's chest position** automatically. This is more accurate than light barriers which can be triggered by hands or knees. Multiple phones can be connected as measurement points—start line, intermediate splits, and finish line.

#### Accuracy
- **±0.02 seconds** claimed accuracy
- Independent study from SRM Institute of Science and Technology confirmed "excellent inter-device reliability"
- Over 75% of measurements accurate to within 0.01s
- Remainder within 0.02s
- Claims to outperform traditional light barrier systems (±0.04s)

#### Core Features

**Automatic Detection:**
- AI-powered chest position identification
- Avoids false triggers from hands/thighs
- Automatic photo finish image capture
- Real-time detection feedback

**Multi-Device System:**
- Connect multiple phones as measurement points
- Unlimited distance between gates
- Only host phone needs Pro subscription
- Internet connection required for sync (minimal data)

**Start Methods (5 Types):**
1. Ready/Set/Go (block starts)
2. Three/Two/One countdown
3. Sound Detection (starting pistol)
4. Touch/Thumb Start (release-based)
5. Flying Start (first detection triggers clock)

**Training Modes:**
- **Basic Mode** - Single athlete, simple setup
- **Advanced Mode** - Multiple phones, manual start control
- **Series Mode** - Fully automated workouts with:
  - Multiple athletes
  - Automatic rest timers
  - Interval training
  - Customizable series and breaks

**Data Management:**
- Unlimited workout history storage
- CSV export functionality
- Athlete profile creation
- Photo finish images saved

#### Pricing Tiers

| Tier | Price | Features |
|------|-------|----------|
| Basic (Free) | $0 | Single phone, lap timing, flying start, chest detection, photo capture |
| Pro Monthly | ~$9.99/mo | Multi-phone, multiple athletes, all start modes, CSV export, series mode |
| Pro Yearly | ~$49.99/yr | Same as Pro Monthly (50% savings + 6 free months advertised) |

*Note: Only the host device needs Pro subscription for multi-device features*

#### Technical Requirements
- Smartphone with camera
- Internet for multi-device sync
- Recommended distance: 1-3 meters from track
- Good lighting conditions
- Stable phone mounting

#### Sports Supported
- Track & Field sprints
- Hurdles
- Relays
- General athletic training
- Any timed running activity

#### Strengths
- **Most direct competitor to Track Speed**
- Proven accuracy with independent validation
- Multi-device support
- Free tier available
- Cross-platform (iOS + Android)
- No external hardware needed
- Chest detection (more accurate than beam break)

#### Weaknesses
- Subscription model for advanced features
- Requires internet for multi-phone sync
- Detection depends on lighting/positioning
- No ghost gate / background subtraction
- Limited to chest crossing detection
- No velocity/speed calculations shown
- No flying start with fly-in zone configuration

## Summary: Track Speed vs Photo Finish

**Photo Finish** is our most direct competitor. Key differentiators for Track Speed:

1. **Ghost Gate Technology** - Background subtraction for faster, more reliable detection
2. **Advanced Flying Starts** - Configurable fly-in zones and timed segments
3. **Offline Multi-Phone** - No internet required for device sync
4. **Free Full Features** - No subscription wall for core functionality
5. **Velocity Calculations** - Real-time speed display in m/s and km/h
6. **Sub-frame Interpolation** - Higher timing precision

**Photo Finish advantages we should consider adding:**
1. Series/Interval training mode with automatic rest timers
2. Sound detection for starting pistol
3. Android support
4. Independent accuracy validation/study
